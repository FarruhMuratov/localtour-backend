## Why
Управление Firebase/Firestore через веб-интерфейс может быть медленным и неудобным для рутинных задач, таких как массовое обновление данных или настройка конфигураций. Создание командного центра (CLI-инструмента) позволит автоматизировать эти задачи, значительно ускорить разработку и упростить управление бэкендом.

## What Changes
- Будет создана новая директория `admin_scripts` в корне проекта.
- Внутри будет разработан CLI-инструмент на Python (`admin_tool.py`), использующий Firebase Admin SDK для прямого взаимодействия с бэкендом.
- Инструмент будет поддерживать различные команды для управления данными. Первая команда будет `update-user-schema` для добавления новых полей существующим пользователям.
- Будет создан файл `requirements.txt` для управления зависимостями.
- Будет предоставлена инструкция по безопасной настройке ключа доступа (Service Account Key) для Firebase Admin SDK.

## Impact
- **Затронутые спецификации:** Будет создана новая спецификация `admin-tools` для описания функционала командного центра.
- **Затронутый код:**
  - Будут созданы новые файлы в директории `admin_scripts/`.
- **Безопасность:** Потребуется безопасное хранение ключа доступа Firebase, который не должен попасть в систему контроля версий (Git).
