## 1. Настройка окружения
- [ ] 1.1. Создать директорию `admin_scripts` в корне проекта.
- [ ] 1.2. Создать и заполнить `admin_scripts/requirements.txt` (зависимости: `firebase-admin`, `python-dotenv`, `click`).
- [ ] 1.3. Создать файл `admin_scripts/.gitignore` чтобы исключить из Git файлы с ключами (`serviceAccountKey.json`, `.env`).
- [ ] 1.4. Подготовить инструкцию для пользователя по получению и размещению файла `serviceAccountKey.json` и созданию `.env` файла.

## 2. Разработка CLI-инструмента
- [ ] 2.1. Создать основной файл `admin_scripts/admin_tool.py`.
- [ ] 2.2. Реализовать базовую структуру CLI с использованием библиотеки `click`.
- [ ] 2.3. Реализовать логику инициализации Firebase Admin SDK с использованием `serviceAccountKey.json`.

## 3. Реализация первой команды: `update-user-schema`
- [ ] 3.1. Создать команду `update-user-schema` в `admin_tool.py`.
- [ ] 3.2. Реализовать логику, которая:
  - [ ] Получает всех пользователей из коллекции `users` в Firestore.
  - [ ] Для каждого пользователя проверяет наличие определенных полей (например, `displayName`, `createdAt`, `roles`).
  - [ ] Если поле отсутствует, добавляет его со значением по умолчанию.
- [ ] 3.3. Добавить выводы в консоль для информирования о прогрессе и результатах.

## 4. Тестирование
- [ ] 4.1. Провести ручное тестирование команды `update-user-schema` на тестовых данных в эмуляторе Firestore.
