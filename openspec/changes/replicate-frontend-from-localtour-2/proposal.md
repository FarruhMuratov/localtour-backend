## Запрос на изменение: Полная замена фронтенда

### 1. Обоснование

Текущий фронтенд проекта, основанный на Create React App (CRA), устарел и не соответствует современным стандартам разработки. Новый фронтенд, расположенный в директории `C:\Users\User\damdaman\localtour-2`, использует современный инструментарий (Vite, TypeScript), предлагает улучшенную производительность и более чистую архитектуру.

Цель этого изменения — полностью заменить старый фронтенд новым, интегрировав его с существующим Firebase бэкендом.

### 2. Затрагиваемые компоненты

- **Весь фронтенд-слой приложения:** папки `src` и `public`.
- **Конфигурация сборки:** переход с `react-scripts` на `Vite`.
- **Файлы конфигурации:** `package.json`, `firebase.json`, `.gitignore`, `tailwind.config.js`, `postcss.config.js`.
- **Документация:** `README.md` будет обновлен с новыми инструкциями.
